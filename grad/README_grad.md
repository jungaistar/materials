# grad — 예제 데이터 (교육용 가상 데이터)

전남대학교 대학원생 대상 AI 활용 교육(이공계열) 실습용입니다.

> **교육용 가상 데이터입니다. 실제 시험 결과가 아닙니다. 논문 · 보고서에 인용하지 마세요.**
> 수식과 난수로 만든 숫자이며, 실제 셀 · 제조사 · 연구실과 관계없습니다.

| 파일 | 내용 |
|---|---|
| `battery_cycling_demo.csv` | 정제 전. 268행(264행 + 중복 4행). 일부러 문제 5종을 넣었습니다. |
| `battery_cycling_clean.csv` | 정제 후(대조용). 264행. 결측 8칸은 채우지 않고 빈칸으로 두었습니다. |
| `AI_Research_Workbook.xlsx` | 산출물 기록용 워크북 |

## 열 설명

| 열 | 뜻 | 단위 · 값 |
|---|---|---|
| `cell_id` | 셀 번호 | C01 ~ C24 |
| `lot` | 제조 lot | A · B · C |
| `temp_c` | 시험 온도 | 25 · 45 (℃) |
| `c_rate` | 충전율 | 0.5 · 1.0 (C) |
| `cycle` | 충방전 횟수 | 0, 50, …, 500 |
| `capacity_ah` | 방전 용량 | Ah |
| `retention_pct` | 용량유지율 = 그 셀의 용량 ÷ 0사이클 용량 × 100 | % |
| `ir_mohm` | 내부저항 | mΩ |
| `max_temp_c` | 시험 중 표면 최고 온도 | ℃ |
| `test_date` | 측정일 | YYYY-MM-DD |

24셀 = 온도 2 × 충전율 2 × lot 3 × 셀 2. 같은 셀을 11번 잰 **반복측정** 자료입니다.

## 정제 전 파일에 일부러 넣은 문제 5종

1. 중복 행 4개
2. 결측 8칸 (`ir_mohm` 3 · `max_temp_c` 3 · `capacity_ah` 2)
3. `temp_c` 표기 혼용 (`45C`, 앞에 공백이 붙은 ` 25`)
4. 한 셀(C17)의 `capacity_ah` 가 mAh 단위
5. 소수점 실수로 보이는 이상값 1개 (`retention_pct` 가 1/10)

생성기: 사이트 리포 `scripts/make-data.py` (난수 씨앗 고정 — 다시 돌려도 같은 파일이 나옵니다).
