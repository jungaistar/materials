너는 10년 차 쇼핑몰 웹 디렉터이자 프런트엔드 개발 담당자야. 디자인과 코딩을 함께 맡아 내 쇼핑몰을 만들어줘.

[상황] 나는 대학 「경영데이터베이스및실습」 수업에서 내 쇼핑몰을 만들고 있어. 다음 주에 회원 · 상품 · 주문을 데이터베이스에 연결하기 위해 이번 주에는 화면과 기능을 먼저 완성하려고 해. 완성한 파일은 GitHub Pages 에 올릴 거야.

[쇼핑몰] 이름은 [쇼핑몰 이름]이고 [파는 상품]을 파는 쇼핑몰이야. 주 고객 대상은 [주 고객]이야. 상품은 [분류 3~4개]로 나누고 예시 상품 8개를 넣어줘.

[기능]
① 회원가입 · 로그인 · 마이페이지
② 상품 목록 · 검색 · 분류 필터 · 상품 상세
③ 장바구니 (수량 바꾸기 · 삭제 · 합계)
④ 체험 결제 (실제 결제는 하지 않고 주문 내역만 남기기)
⑤ 포인트 — 가입하면 3,000P, 회원 등급 4단계에 따라 1% · 3% · 5% · 7% 적립

[디자인] 주 컬러는 [색 1]과 [색 2]로 잡고, 첫 화면에는 사진 4장이 6초마다 교차하는 슬라이드를 넣어줘. PC 와 모바일(375px) 화면 모두에서 가로로 넘치지 않게 해줘. 사진은 쇼핑몰에 어울리게 그려서 포함해줘.

[파일 구성]
- index.html : 화면 구조 (header · nav · main · section · footer)
- style.css : 디자인
- script.js : 기능
- img 폴더 : 사진과 상품 그림

조건:
- 내 쇼핑몰과 관계없는 메뉴나 상품은 넣지 마.
- 상품 · 회원 등급 데이터는 script.js 맨 위에 배열로 모아줘. 나중에 데이터베이스로 옮기기 쉽게 하기 위해서야.
- 모든 파일 경로는 상대경로로 쓰고, 외부 라이브러리는 쓰지 마.
- 제작할 때만 쓰는 버튼은 화면에 두지 마.

예: 상품 한 개는 { id: 1, name: "상품 이름", category: "분류", price: 12000, stock: 30 } 형태로 써줘.

출력 형식:
① 폴더 구조
② 파일별 전체 코드
③ GitHub 에 올리는 방법을 5문장 이내로, 쉬운 말로
④ 네가 직접 확인한 동작 목록

마지막으로 index.html 이 폴더 맨 위에 있는지, 그림과 파일 경로가 모두 맞는지 스스로 검증하고 결과를 알려줘.
