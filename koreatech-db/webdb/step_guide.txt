=====CARD 01-sb-06-sql-editor
1. 표 만들기 — SQL 을 붙여 넣고 Run
-----BODY
① 「11월 - 웹DB 실습 강의」 칸의 shop_supabase.sql 을 열어 전체를 복사합니다. (Ctrl + A → Ctrl + C)
② Supabase 왼쪽 메뉴 SQL Editor → New 로 빈 창을 엽니다.
③ 붙여 넣고(Ctrl + V) 오른쪽 위 초록 Run 을 누릅니다.
④ 아래에 Success 가 나오면 끝입니다.

경고 창이 뜨면 읽고 실행을 누릅니다. 데이터를 지우는 것이 아닙니다.
=====CARD 02-sb-07-table-editor
2. 표가 생겼는지 보기
-----BODY
① 왼쪽 메뉴 Table Editor 를 누릅니다.
② shop_ 으로 시작하는 표 4개가 보이는지 봅니다.
③ shop_products 를 누르면 예시 상품 6개가 들어 있습니다.

4개가 보이지 않으면 1번으로 돌아가 Run 을 다시 누릅니다.

[표 구조] shop_profiles ( id, email, name, phone, grade, points, role )

[표 구조]
- shop_orders ( id 자동 번호, user_id, total, status )
- shop_order_items ( order_id, product_id, qty, unit_price )

할 일:
① 결제를 누르면 로그인했는지 먼저 확인하고, 안 했으면 로그인 화면으로 보내줘.
② shop_orders 에 { total } 한 줄을 넣고, .select().single() 로 방금 만든 주문의 id 를 받아줘.
③ 그 id 로 shop_order_items 에 장바구니 상품을 { order_id, product_id, qty, unit_price } 로 넣어줘.
④ 성공하면 장바구니를 비우고 주문 번호와 합계를 보여줘.

조건:
- 디자인과 지금 있는 다른 기능은 하나도 바꾸지 마.
- 파일마다 코드 상자를 따로 쓰고, 상자 위에 파일 이름을 적어줘.
- 고친 파일은 바뀐 줄만 주지 말고 파일 전체를 줘.
- 표 이름과 열 이름은 내가 적은 것과 한 글자도 다르지 않게 써줘.
- user_id 와 status 는 보내지 마. DB 가 자동으로 넣어.
- 장바구니에 같은 상품이 두 번 있으면 수량을 합쳐 한 줄로 보내줘.
- 포인트와 재고는 표에 저장하지 마. DB 가 막아 두었어. 화면에 「적립 예정 nP」 로만 보여줘.
- 실제 결제는 하지 않아. 카드 번호는 받지 마.

마지막에 「저장소에 올릴 파일」 을 표로 알려줘. (파일 이름 · 새 파일인지 덮어쓰기인지)
=====CARD 14-step-14-error
14. 막혔을 때
-----BODY
① 내 쇼핑몰에서 F12 → Console 을 엽니다.
② 빨간 글자를 끌어서 복사합니다.

자주 나오는 빨간 글자

· Invalid API key — 4번의 키를 다시 복사해 넣습니다.
· Email not confirmed — 11번을 합니다.
